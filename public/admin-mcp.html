MCP设置

关闭后 /mcp 一律返回 503（fail-closed），AI 工具无法访问。修改立即生效，无需重启。

留空 = 不启用 DNS 重绑定防护（默认）。填了之后只有这些 Host 头的请求能通过。 只写主机名，不要带端口或协议。

申请令牌

仅用于自己辨认，令牌本身与名称无关。

勾选「写入」会自动包含同族的「读取」。没勾选的权限不会出现在该令牌的工具列表里。

产品没有「上架」权限 —— AI 建出来的产品一律是草稿，上架必须人工在「产品管理」里点。

使用说明

Claude Code（命令行）

claude mcp add --transport http booming-news https://www.booming.one/mcp \
  --header "Authorization: Bearer <你申请的令牌>"

Claude Desktop / 其它 MCP 客户端

{
  "mcpServers": {
    "booming-news": {
      "type": "http",
      "url": "https://www.booming.one/mcp",
      "headers": { "Authorization": "Bearer <你申请的令牌>" }
    }
  }
}

主令牌

主令牌在上方「主令牌」区生成，拥有全部权限，可以随时复制出来。 它的用途是「逃生口」—— 万一后台令牌全部吊光了，还能靠它恢复访问。 日常给 AI 工具用的应该是下面申请到的、带作用域的令牌。

吊销

令牌泄露时在下方「令牌列表」点吊销即可，该令牌立刻失效（下次请求返回 401），不影响其它令牌。 吊销记录会写入操作日志，可在「系统日志 → 操作日志」查看。
